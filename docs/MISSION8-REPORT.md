## 3. Deep Reverse Engineering of ECHO-WEBSITE

The reference application at `/mnt/d/Vyuk Projects/ECHO-WEBSITE/` was inspected in detail both via filesystem disassembly and live execution on `http://localhost:8085`.

### 1. The WorksWheel 3D Vertical Drum & Ring Engine (`works-wheel.js`)
ECHO's signature works carousel does not use flat slides or basic card carousels. It projects items onto a virtual cylindrical drum in 3D coordinate space with radial bowing and perspective distortion:

- **Mathematical Constants:**
  - `CARD_H = 0.38` (front card height as fraction of stage)
  - `CARD_MAX_W = 0.34` (maximum width threshold)
  - `CARD_RATIO = 1.45` (width-to-height ratio)
  - `STEP = 40` (degrees separating adjacent cards along the cylindrical surface)
  - `DRUM = 2.22` (drum radius in card heights)
  - `LENS = 2.7` (perspective depth in card heights: `perspective: depth px`)
  - `RING_R = 1.14` (planar ring radius)
  - `BOW = 1.82` (lateral curve displacement factor)
  - `EASE = 0.12` (fractional convergence per RAF frame)
  - `SETTLE = 140ms` (inertia timeout snapping `target` to nearest integer)

- **3D Projection Equation:**
  ```javascript
  const bowAt = (drumDeg, bow) => -bow * (1 - Math.cos((drumDeg * Math.PI) / 180));

  function place(ringDeg, drumDeg, ringR, drumR, bow, m) {
    return (
      `translateX(${m * bowAt(drumDeg, bow)}px)` +
      ` rotateZ(${(1 - m) * ringDeg}deg) translateY(${-(1 - m) * ringR}px)` +
      ` rotateX(${m * drumDeg}deg) translateZ(${m * drumR}px)`
    );
  }
  ```

- **Motion Choreography:**
  - `target` accumulates fractional scroll/drag delta (`diff / DRAG_UNITS` or `deltaY / WHEEL_UNITS`).
  - Single RAF loop computes `gap = target - turn` and updates `turn += gap * EASE`.
  - As card index `i` deviates from current position `pos` (`d = i - pos`), card rotation angle is `d * STEP`.
  - Cards facing away (`|d| > CULL`) are culled (`opacity: 0; pointer-events: none;`) to maximize framerate.
  - Active card receives subtle scale enhancement, highlighted border, and synchronized side index illumination.

### 2. Implementation in Rayhan Portfolio (`WorksWheel3D.tsx`)
This exact mathematical engine was translated into `src/components/ui/WorksWheel3D.tsx` in Next.js/React with:
- Touch pan and pointer drag support (`setPointerCapture`).

- Step navigation buttons (`Prev` / `Next`) and keyboard arrows (`ArrowUp`, `ArrowDown`, `ArrowLeft`, `ArrowRight`).

## 4. Anime-Inspired Typography Research & Integration

### 1. Evaluation of MyFonts Anime Tag Collection (`https://www.myfonts.com/pages/tags/anime-fonts/`)
Five real commercial typefaces from the anime/manga typography landscape were evaluated:

1. **The Last Shuriken** (Blambot Comic Fonts)  
   - *Design Characteristics:* Dynamic katana-cut terminals, forward-leaning italic urgency, bold comic sound-effect aesthetic.  
   - *Assessment:* Exceptional character for punchy graphics, but too informal for an engineering systems portfolio.
2. **Shinobu** (Typodermic Fonts)  
   - *Design Characteristics:* Ultra-wide geometric brutalism, sharp 45-degree chamfers, heavy cinematic sci-fi anime title weight.  
   - *Assessment:* Powerful graphic presence; exemplifies the mecha/cyberpunk Japanese aesthetic.
3. **VideoTech** (Device Fonts)  
   - *Design Characteristics:* Pixelated arcade meets 90s OVA anime screen titles; strict grid-aligned strokes.  
   - *Assessment:* High retro novelty, but limited legibility for production technical specs.
4. **Halcom** (The Northern Block)  
   - *Design Characteristics:* Precision engineered geometric neo-grotesque with subtle sci-fi anime incisions; clean, restrained, modern.  
   - *Assessment:* High usability, strong editorial discipline.
5. **Manbokun** (Visual Audio)  
   - *Design Characteristics:* Chunky, high-impact Japanese poster display font with compact counters and ultra-heavy stems.  
   - *Assessment:* Visually arresting for massive display mastheads.

### 2. Selected Font Integration: Dela Gothic One & Chakra Petch
To achieve award-level anime title character without cartoonish tropes or commercial licensing encumbrances:

1. **Dela Gothic One (`@fontsource/dela-gothic-one`)** — Display Mastheads:
   - A Japanese gothic display font designed with flat, heavy strokes, compact counters, and extraordinary mass.
   - Evokes the aesthetic of *Neon Genesis Evangelion*, *Akira*, and modern Japanese game title screens.
   - Applied to the Hero masthead (`RAYHAN KHAN`), section titles (`Flagship Systems`, `Engineering Matrix`, `Achievements`), and active project modal titles.
2. **Chakra Petch (`@fontsource/chakra-petch`)** — Architecture Subtitles & Technical Badges:
   - Square-proportioned geometric display face with 45-degree chamfered terminals inspired by mecha anime UI.
   - Applied to section kickers, technical discipline labels, milestone badges, and navigation anchors.
3. **Instrument Sans (`@fontsource/instrument-sans`)** — Body Text:
   - Clean, highly legible contemporary grotesque providing reading comfort across dense architectural descriptions.
4. **Chivo Mono (`@fontsource/chivo-mono`)** — Technical Telemetry & Code:
   - High-contrast variable monospace for timecodes, performance metrics, and model names.
